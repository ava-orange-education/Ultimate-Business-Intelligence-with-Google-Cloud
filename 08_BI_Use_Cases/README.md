# NordLeaf BI Use Cases
## Inspired by Stora Enso — Finnish Paper Manufacturing

NordLeaf is a vertically integrated Finnish paper manufacturer:
- **Owns forests** (timber supply)
- **Operates 5 mills** across Finland
- **Manages supply chain** (pulp, chemicals, energy, logistics)
- **Sells to 18 EU customers** (publishers, packagers, retailers)

These use cases cover every business domain using the actual BigQuery data model.
